# MedStar Hospital Website

This is a responsive hospital website built with HTML and CSS. It includes a home section, an about section, hospital statistics, services, and pricing plans with booking buttons.

## Project Contents

- `index.html`: The structure and content of the website.
- `style.css`: The website styles, colors, and layout.
- `img/`: Images used throughout the website.

## Running the Project

1. Open the project folder in VS Code.
2. Open `index.html` in a browser.

## Technologies Used

- HTML5
- CSS3
- Font Awesome
